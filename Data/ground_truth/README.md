# ground_truth คืออะไร และต้องใส่อะไรในนี้

โฟลเดอร์นี้เก็บ **ข้อความที่เราอ่านเทียบกับ PDF แล้วว่าถูกต้อง** เพื่อเป็นเฉลยให้ notebook ตรวจผล OCR

```text
ข้อความที่เราตรวจจาก PDF แล้ว  ← ใช้เป็นเฉลย
ข้อความที่โมเดล OCR อ่านได้    ← ใช้เป็นคำตอบที่ต้องตรวจ
                  ↓
         notebook เปรียบเทียบว่าต่างกันเท่าไร
```

เราเรียกเฉลยนี้ว่า **ground truth** หรือ **reference** เป็นสิ่งเดียวกันในคู่มือนี้

## ต้องทำครบทั้งเล่มไหม

**ยังไม่ต้องครับ เริ่มภาษาอังกฤษ 5 หน้าก่อน: 1, 10, 20, 36 และ 39** โดยหนึ่งไฟล์เก็บข้อความครบหนึ่งหน้า ไม่ใช่ทั้งเล่ม

ใช้ PDF อังกฤษใน [Data/raw](../raw/) และนับหน้าตามลำดับที่โปรแกรมเปิด PDF แสดง เช่น หน้าที่ 36 จาก 39 หน้า ไม่ใช้เลขหน้าที่พิมพ์อยู่ในเนื้อหาเป็นตัวเลือกหน้า

## เริ่มทำหนึ่งหน้าอย่างไร

เริ่มจาก **หน้า PDF 36** ที่เราพบปัญหาแล้ว:

1. เปิด PDF อังกฤษไปที่หน้า 36
2. คัดลอกข้อความของหน้านั้นจาก PDF มาเป็นร่างได้ หากคัดลอกไม่ได้ให้พิมพ์เอง
3. อ่านเทียบกับภาพ PDF ทุกบรรทัด แล้วแก้ร่างให้ตรงภาพ โดยเฉพาะเลขมาตรา จำนวนเงิน และคำปฏิเสธ เช่น `not`
4. สร้างโฟลเดอร์ `en` ภายใน `ground_truth` หากยังไม่มี
5. เมื่อข้อความถูกตรวจครบแล้ว บันทึกเป็น `en/page_036.txt` โดยเลือก encoding เป็น UTF-8

**อย่าคิดว่าข้อความที่คัดลอกจาก PDF ถูกเสมอ** ต้องตรวจภาพก่อน และอย่าคัดลอกผล OCR มาใช้เป็นเฉลยโดยไม่ตรวจ เพราะจะกลายเป็นให้คะแนนคำตอบกับตัวเอง

ถ้ายังตรวจไม่เสร็จ ให้เก็บร่างไว้ที่อื่นก่อน notebook จะถือว่าไฟล์ `page_*.txt` ในโฟลเดอร์นี้พร้อมใช้เป็นเฉลยแล้ว

## ในไฟล์ต้องมีข้อความแค่ไหน

| ใส่ในไฟล์ | ไม่ต้องใส่ |
|---|---|
| ข้อความครบหน้าที่กำลังตรวจ ตามลำดับการอ่าน | ข้อความจากหน้าก่อนหรือหน้าถัดไป |
| หัวกระดาษ เช่น ชื่อเอกสารและวันที่ | เลขหน้ากระดาษที่อยู่บนหัวหรือท้ายหน้า |
| หัวข้อมาตรา เนื้อหา และคำบรรยายภาพที่มีอยู่จริง | รูปภาพ หรือคำบรรยายที่โมเดลแต่งขึ้น |
| ตัวสะกด ตัวเลข และเครื่องหมายตาม PDF | เครื่องหมาย Markdown ที่เติมเพื่อจัดรูปแบบ เช่น `#` หรือ `**` |

ถ้าหน้า 36 เริ่มกลางประโยค ให้เริ่มไฟล์จากคำนั้นเลย ไม่ต้องยกต้นประโยคจากหน้า 35 มาเติม และถ้าประโยคยังไม่จบที่ท้ายหน้า ก็ไม่ต้องต่อข้อความจากหน้า 37

ไฟล์นี้เป็น `.txt` ข้อความล้วน ไม่ต้องใส่ JSON ชื่อไฟล์ คำอธิบาย หรือข้อความว่า “นี่คือหน้า 36” ลงในเนื้อหา และไม่แก้สำนวนของต้นฉบับให้ดีขึ้น

## ทำครบ 5 หน้าแล้วจะได้แบบนี้

```text
Data/ground_truth/
├── README.md
└── en/
    ├── page_001.txt  ← ข้อความครบหน้า PDF 1
    ├── page_010.txt  ← ข้อความครบหน้า PDF 10
    ├── page_020.txt  ← ข้อความครบหน้า PDF 20
    ├── page_036.txt  ← ข้อความครบหน้า PDF 36
    └── page_039.txt  ← ข้อความครบหน้า PDF 39
```

ไม่จำเป็นต้องรอครบ 5 หน้า เริ่มจากไฟล์หน้า 36 เพียงไฟล์เดียวแล้วทดลองรันได้ แต่คะแนนตอนนั้นจะเป็นผลของหน้า 36 เท่านั้น อย่าสร้างไฟล์ว่างของหน้าที่ยังไม่ทำ

## จากนั้นทำอะไรต่อ

เปิด [04_ocr_evaluation.ipynb](../../Backend/notebooks/04_ocr_evaluation.ipynb) เลือก `LANGUAGE = 'en'` แล้วรันตามลำดับ notebook จะอ่านเฉลยจาก `en/page_*.txt` และแสดงคะแนนกับจุดที่ OCR อ่านต่างออกไป

เมื่อทดลองโมเดลอื่น ใช้เฉลยชุดเดิมเพื่อเปรียบเทียบอย่างเท่าเทียมกัน คะแนน 5 หน้าบอกผลเฉพาะชุดนี้ ยังไม่รับรองทั้งเล่ม ก่อนเลือกโมเดลสุดท้ายค่อยตรวจหน้าใหม่เพิ่มอีกเล็กน้อย

ตอนนี้เริ่มอังกฤษก่อนก็พอ เมื่อจะวัดภาษาไทยจึงทำแบบเดียวกันใน `th/page_001.txt` และเปลี่ยน `LANGUAGE = 'th'`

รายละเอียด metric และกราฟอยู่ใน [คู่มือ evaluation](../../Backend/notebooks/04_ocr_evaluation_GUIDE.md)
