# Experiment log

โฟลเดอร์นี้เก็บบันทึกการทดลองจริงของโปรเจกต์ PDPA-RAG โดย agent เป็นผู้เขียนและปรับปรุงสรุปจากขั้นตอน ผลลัพธ์ และข้อสังเกตที่เกิดขึ้นจริง เจ้าของโปรเจกต์เป็นผู้ลงมือทำและตัดสินใจเกี่ยวกับการทดลอง

## การตั้งชื่อ

ใช้ไฟล์ Markdown หนึ่งไฟล์ต่อการทดลอง เช่น `001-pdf-extraction.md`, `002-chunk-size.md` เรียงลำดับตามเวลาที่ทดลอง

## สิ่งที่ต้องบันทึก

1. **คำถาม/สมมติฐาน:** กำลังตรวจอะไร
2. **ข้อมูลและวิธี:** ใช้ไฟล์ใด เครื่องมือหรือค่าตั้งต้นอะไร และทำขั้นตอนไหนจริง
3. **ผลที่สังเกตได้:** ตัวเลข ตัวอย่างข้อความ ปัญหา หรือภาพหน้าจอที่ตรวจสอบย้อนกลับได้
4. **การเปรียบเทียบ:** ถ้ามี baseline ให้ระบุสิ่งที่เปลี่ยนเพียงปัจจัยเดียวและผลก่อน/หลัง
5. **ข้อสรุปและขั้นถัดไป:** แยกผลที่พิสูจน์แล้วออกจากข้อสันนิษฐาน พร้อมบันทึกการตัดสินใจของเจ้าของโปรเจกต์

หากข้อมูลไม่ครบ ให้ระบุว่า `ยังไม่ได้ตรวจ` หรือ `ยังไม่ได้ทดลอง` ห้ามเติมผลลัพธ์หรือสรุปแทนหลักฐาน

การทดลองแรกที่คาดว่าจะบันทึกคือการดึงข้อความจาก PDF ภาษาไทยและอังกฤษ แล้วสุ่มเทียบกับหน้า PDF ต้นฉบับ ขณะนี้ยังไม่มีผลการทดลองที่บันทึกไว้
